# PASTA Threat Model: Sneaker Marketplace App

## Overview
This case study applies the Process for Attack Simulation and Threat Analysis (PASTA) framework to a fictional pre-launch mobile marketplace app connecting sneaker buyers and sellers. Unlike an incident response report, this is a proactive assessment: the goal is to evaluate an application's security posture *before* launch and determine what must be fixed first.

## What This Demonstrates
- Working through all seven stages of a recognized application threat modeling framework, from business objectives through to prioritized remediation
- Reasoning about technical architecture trade-offs (why one technology's attack surface matters more than another) 
- Building an expanded data flow diagram and attack tree from scratch, tracing how a specific architectural decision creates a specific exploitable path
- Rating findings by severity (Critical/High/Medium) with references to industry standards (CWE, OWASP Top 10)
- Structuring the deliverable for a leadership audience, with an executive summary, a stated scope, and a launch/no-launch recommendation up front, backed by a remediation table with owner and timeline assignments
- Making assumptions explicit where the underlying business brief didn't fully specify the architecture, as would be expected in a real engagement

## Skills Demonstrated
- Application threat modeling (PASTA)
- Data flow diagram and attack tree construction
- Secure architecture review (API, PKI, hashing, database layers)
- Vulnerability prioritization and launch risk decision-making
