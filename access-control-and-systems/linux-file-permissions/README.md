## 🎯 Project Overview
As a cybersecurity professional supporting an internal research team, I conducted an authorization and access-control audit on the `/home/researcher2/projects` directory. The existing file system permissions did not align with organizational authorization policies and exposed critical project assets to unauthorized modifications. 

Using Linux command-line tools in a Bash shell, I audited the directory structure, deconstructed permission strings, and enforced the **Principle of Least Privilege** using `chmod` to restrict access across users, groups, and world/other.
