# Network Traffic Analysis

Case studies analyzing network packet captures to identify, document, and respond to security incidents.

## Contents

- [`syn-flood-attack/`](./syn-flood-attack) — SYN flood denial-of-service investigation using Wireshark packet capture analysis. Identifies an attack pattern from raw TCP traffic, explains the underlying handshake exploitation, and recommends mitigations.
- [`brute-force-redirect/`](./brute-force-redirect) — Brute force attack investigation using tcpdump, tracing a malicious website redirect back to a compromised administrative account. Combines packet-level evidence with source code review and incident documentation.

## Skills Demonstrated Across This Section

- Packet capture analysis (Wireshark, tcpdump) and TCP/IP protocol interpretation
- Attack pattern recognition from raw traffic logs
- Incident documentation with clear evidence sourcing
- Security control recommendations grounded in root cause analysis

## Context

These case studies were completed as part of the Google Cybersecurity Professional Certificate coursework. Scenarios and log data are course-provided simulations, not real client incidents.
